A fresh collection.
Every morning.

Choose the photos you love once. Your iPhone can send a different selection to the frame each day.

Photos album → Daily Shortcut → Your frame

1. Make your album

In Photos on your iPhone, create an album named Dash Frame. Add the pictures you would like to see. The Shortcut chooses up to 24 at random; adding more gives you a different mix each day.

Still photos work best. Live Photos can be converted to still JPEGs; exclude videos. Portrait photos fill the display using a crop you can adjust in Apps → Photos.

2. Connect your frame

Deploy the photo functions to your existing Convex project and set its private DASH_FRAME_TOKEN environment variable. Enter that same token in Apps → Photos → Connection on Dash, together with the deployment's .convex.site URL.

This page fills in your configured URL when available. Photo requests use .convex.site; existing phone-status Shortcuts continue using .convex.cloud.

The photo token is shown only when you set it up. Dash saves it privately and never returns it to this page. Keep the same token in the Shortcut described below.

3. Build “Send photos to Dash”

In Shortcuts, create a new shortcut named Send photos to Dash. Use these actions in order. Wherever a value is in square brackets below, insert that action's magic variable, rather than typing the brackets.

  1. Add Text containing your photo token; use Set Variable to name it Photo Token.
  2. Add Find Photos: Album is Dash Frame, Media Type is Image, Sort by Random, Limit 24. If it says Filter Photo Token, tap that input variable and choose Clear so it searches All Photos. Add Set Variable, name it Selected Photos, and select the Photos output.
  3. Count Selected Photos. If the count is 0, use Stop This Shortcut. Otherwise save the count as Photo Count.
  4. Add Generate UUID and save it as Request ID. Add Current Date → Format Date with custom format yyyy-MM-dd; save it as Batch Date.
  5. Get Contents of URL using the start request below. Choose a JSON request body and add its three fields individually. Add expected_count as a Number field. Immediately afterward, add Get Dictionary Value: key batch_id, dictionary Contents of URL from this start request. Add Set Variable: name Batch ID, value Dictionary Value. Batch ID is returned by Convex; Request ID is the UUID you generated earlier. Add If Batch ID does not have any value → Show Result with the start request's Contents of URL → Stop This Shortcut → End If.
POST /frame/batches/start
Headers:
  Authorization: Bearer [Photo Token]
  Content-Type: application/json
JSON fields:
  request_id: [Request ID]
  expected_count: [Photo Count]
  date: [Batch Date]
  1. Add Repeat with Each item in Selected Photos. First inside the loop, add Convert Image: input Repeat Item, format JPEG, high quality, Preserve Metadata off. Add Set Variable: name SourceJPEG, value Converted Image from this action. Convert before resizing: testing on the iPhone found an empty resize result for a Photos item that worked when converted to JPEG first.
  2. Use Get Details of Images to get Width and Height from SourceJPEG. Set Resized Photo to SourceJPEG first. If either dimension exceeds 2048, add an inner If Width is greater than Height: Resize Image with input SourceJPEG, width 2048, height Auto. In Otherwise, resize SourceJPEG to height 2048, width Auto; this also handles square photos. Immediately after each Resize action, add Set Variable to assign Resized Photo the Resized Image output from that same branch. End both If blocks. Smaller photos keep SourceJPEG.
  3. Add Convert Image: input Resized Photo, format JPEG, quality approximately 80%, Preserve Metadata off. Add Set Variable: name Upload Photo, value Converted Image from this final conversion.
  4. Calculate Repeat Index minus 1; use Set Variable to save the Calculation Result as Photo Index. Send the upload request below. In Get Contents of URL, choose Request Body → File, tap the File input, and select the Upload Photo variable. This sends the JPEG's actual contents. After the request, add Get Dictionary Value: key id, dictionary Contents of URL from this upload request. Add If Dictionary Value does not have any value → Show Result with the upload request's Contents of URL → Stop This Shortcut → End If. End Repeat.
POST /frame/photos/upload?batch_id=[Batch ID]&index=[Photo Index]
Headers:
  Authorization: Bearer [Photo Token]
  Content-Type: image/jpeg
Request Body: File → [Upload Photo]
  1. After End Repeat, send the commit request below. This makes the complete collection available to Dash. Optional: show a notification only after a successful commit.
POST /frame/batches/commit
Headers:
  Authorization: Bearer [Photo Token]
  Content-Type: application/json
JSON fields:
  batch_id: [Batch ID]

Each photo must be a JPEG under 8 MiB. Delete any empty header rows: a blank header reproduced “The network connection was lost” in Apple's networking API. If a request fails, the old collection stays on screen. You can run the Shortcut again; unfinished batches are cleaned up automatically.

4. Try it, then make it daily

Run the Shortcut manually once, allowing Photos and network access when iOS asks. Check Apps → Photos for the new collection. Dash checks for new photos every minute and downloads the complete set before showing it.

In Shortcuts → Automation, create a Time of Day automation at a convenient morning time, repeating Daily. Choose Run Immediately and run Send photos to Dash. It may take longer when iCloud needs to download selected originals.

Photos change every 15 minutes. Tap the photo to advance immediately and start a fresh 15-minute interval; the position survives a page reload. With 24 pictures, automatic rotation repeats every six hours. A missed automation, empty album, or interrupted upload keeps the last complete collection running.

Tapping the photo also reveals Settings and Apps. Tapping a widget or control does not advance the photo. Photos lets you adjust cropping and clock placement, including bottom left, center, and right. Weather and live activities rearrange around the clock. The web frame stays on while you are home with Sleep Focus off; Away and Sleep Focus still cover the display. Physical OLED motion dimming and sleep behavior remain independent.

If the collection does not arrive

Check the connection status in Apps → Photos. Verify that the server and Shortcut use the same token and that the photo URL ends in .convex.site. Run the Shortcut manually to locate the action that failed, then use the frame's sync control to check again.

New uploads never partially replace the current collection. The two most recent complete collections are retained; abandoned uploads expire after 48 hours.
