Siri Shortcuts & Convex Guide

Trigger state updates from anywhere over Cellular or Wi-Fi

1. Sleep Focus Automation (Turns motion off at night)

In iOS Shortcuts app → Automation tab → + → Sleep → When Bedtime Starts / Sleep Focus turns On → Run Immediately.

Action: Get Contents of URL (POST) URL: https://tremendous-tiger-513.convex.cloud/api/mutation Method: POST Headers: Content-Type: application/json Request Body: {"path": "dashvars:set", "args": {"sleep_focus": true}}

2. Wake Up Automation (Restores normal motion wake)

In iOS Shortcuts → When Waking Up / Sleep Focus turns Off.

Action: Get Contents of URL (POST) Request Body: {"path": "dashvars:set", "args": {"sleep_focus": false}}

3. Leave / Arrive Home (Location or Home Wi-Fi)

In iOS Shortcuts → When Leaving Home / Disconnecting from Home Wi-Fi.

Leave Home Body (Screen Stays Off): {"path": "dashvars:set", "args": {"is_home": false}}
Arrive Home Body (Normal Motion Resumes): {"path": "dashvars:set", "args": {"is_home": true}}

4. Convex Deployment Code (`convex/dashvars.ts`)

Add this file into your Convex project folder to handle the queries & mutations:

import { mutation, query } from "./_generated/server";
import { v } from "convex/values";

export const get = query({
  args: {},
  handler: async (ctx) => {
    const record = await ctx.db.query("dashvars").order("desc").first();
    return record || { sleep_focus: false, is_home: true };
  },
});

export const set = mutation({
  args: {
    sleep_focus: v.optional(v.boolean()),
    is_home: v.optional(v.boolean()),
    focus_mode: v.optional(v.string()),
    battery_level: v.optional(v.number()),
  },
  handler: async (ctx, args) => {
    const existing = await ctx.db.query("dashvars").order("desc").first();
    if (existing) {
      await ctx.db.patch(existing._id, { ...args, updated_at: new Date().toISOString() });
    } else {
      await ctx.db.insert("dashvars", {
        sleep_focus: args.sleep_focus ?? false,
        is_home: args.is_home ?? true,
        focus_mode: args.focus_mode ?? "none",
        updated_at: new Date().toISOString(),
      });
    }
  },
});
